# SWYNEX - Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing raw data for analysis.

## Objective
The objective is to clean the raw dataset by handling missing values, duplicate records, incorrect data types, and formatting issues.

## Dataset
The dataset contains raw data provided for the SWYNEX internship task.

## Data Cleaning Steps
- Checked for missing values
- Removed duplicate records
- Corrected data types
- Removed unnecessary spaces
- Standardized data
- Prepared the cleaned dataset for analysis

## Files
- SWYNEX_raw_data.xlsx - Original raw dataset
- SWYNEX_cleaned_data.xlsx - Cleaned dataset

## Tools Used
- Microsoft Excel
- GitHub
